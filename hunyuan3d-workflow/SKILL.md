# 混元 3D 工作流

## 选择入口

| 入口 | 地址 / 用法 |
|---|---|
| 国内官网 | https://3d.hunyuan.tencent.com/ |
| 国际官网 | https://hy3d.tencent.ai/ |
| 代理 MCP | 已配置且实测支持所需操作时使用；见 [代理参考](references/proxy.md) |

国内、国际、各自主站与 Studio、腾讯云 API 分别记账。读取当前账号和页面余额，不能沿用旧次数或把网页免费次数当云 API 积分。优先复用用户已登录的浏览器，不索要聊天中的 Cookie/密钥。

质量改进任务先检查现有可编辑源、已授权成熟资产和材质，确定缺的是几何、法线还是表面效果；再决定是否需要局部生成。用户明确要求的试产按约定范围执行，不因工具可用就重生整个资产。涉及 Blender 修整及游戏导入时，按需读取 [局部试产与引擎验收](references/asset-refinement.md)。

## 执行

1. 明确输入与目标：文生/图生、重建几何，或在已有模型上做拓扑、UV、纹理、骨骼。打磨用用户指定的最新模型，保留原件；角色白模不等于可动画角色。
2. 查看当前版本、参数、格式限制和扣次提示，先验证当前套餐能下载所需格式及适用的使用权。Tripo/Meshy 等对照服务也先检查导出限制，不花额度生成无法交付的样本；限制以当前账号页面和条款为准。纹理及后处理也可能扣额度。按用户预算执行；仅要求试跑时先做一个任务，提交前简短通知。免费资格不明、余额不足或出现未授权付款流程时停止消费操作。
3. 官网生成在 AI Creation；处理已有模型进 3D Studio，选择角色/道具及对应工具，上传模型。不要为拓扑测试重复生成角色。国际版实测路线为 `Studio → Roles → Retopology`；路径与界面文案以现场为准。
4. 按浏览器工具文档操作上传、等待和下载。若上传超时，先检查是否已创建任务，再做一次有针对性的重试；避免重复扣次。几何处理可用去贴图副本缩小上传，须保持几何并记录变换；纹理任务需保留所需材质/参考图。
5. 提交后记下前后额度、时间、版本/参数、任务标识和状态。跨日刷新或账号并行使用时，余额差不能归因于单个任务；分别报告可确认的提交数、页面标价、余额和实际账单。排队或 99% 不表示完成；按合理间隔查看，失败或卡住时保留证据，不连续重提。跨回合保留任务页供续查。
6. 下载后核验实际文件可读、面数、UV/贴图；角色另查骨骼/权重。在 Blender 和目标引擎按真实尺度检查轮廓、正背面及关键细节；几何不成立先弃用或修形，不追加纹理掩盖缺陷。候选阶段使用隔离副本，正式替换遵守用户授权和项目原有审核流程。FBX 几何异常时用另一导入器检查原件，区分输出与转换问题。四边形源导出 GLB 后会三角化，分别报告源多边形与运行时三角面；减面成功不代表质量通过。

## 交付

给出模型/贴图、预览、输入来源、版本/参数、额度前后值、已验证能力与缺项。保留原始下载和必要的源文件，不把网页模型文件名冒充任务 ID。未下载/未验收的结果要明确标注。

代理仓库的代码许可、官网生成物条款和输入素材权利分别核实；免费额度不等于商用许可。上游标注学习用途且缺少标准许可证时维持研究用途结论。国际版条款单独核对，不套用国内版结论。
